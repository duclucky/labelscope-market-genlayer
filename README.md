# LabelScope Market

LabelScope Market is a GenLayer prediction product where a fully collateralized binary pool settles only after validators agree that official FDA approval language matches the exact indication scope locked by participants.

Status: **BUILDING — Projects Stage 2**

The returned frontend has been audited and the complete one-contract specification is locked. Contract implementation, adversarial tests, Studionet evidence, canonical frontend integration, and publication are in progress.
