# LabelScope Market

LabelScope Market is a GenLayer prediction product where a fully collateralized binary pool settles only after validators agree that official FDA approval language matches the exact indication scope locked by participants.

Status: **SELECTED — Projects Stage 1**

This repository currently contains the validated idea research and the product/frontend blueprint. Contract implementation, network deployment, and frontend integration begin only after the user-created frontend returns for Stage 2.
